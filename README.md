## Interactive reader and PDF export

Download the repository with **Code → Download ZIP**, extract it, and open **index.html** in Chrome or Safari. Each unit has editable notes, search, hints, hidden solutions, and progress tracking. **Export PDF** opens print settings, including handwriting space for apps such as Notability. GitHub previews the Markdown; download the HTML to use the interactive reader.

Your edits stay in your browser. Use **Back up or restore my work** to keep a personal copy. Do not commit personal backups.
